# Runtime.Variables.EMaxLayers

## Description

Available options for the max layers keyword in a Repetitionless material

Each value has an int assigned being the same as its name

Can be directly translated to the keyword _MAX_LAYERS_X

## Members

| Member | Description |
|--------|-------------|
| Four | = 4 |
| Eight | = 8 |
| Twelve | = 12 |
| Sixteen | = 16 |
| Twenty | = 20 |
| TwentyFour | = 24 |
| TwentyEight | = 28 |
| ThirtyTwo | = 32 |
