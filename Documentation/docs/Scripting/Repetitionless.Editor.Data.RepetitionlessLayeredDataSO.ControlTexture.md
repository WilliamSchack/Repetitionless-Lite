# Editor.Data.RepetitionlessLayeredDataSO.ControlTexture

## Description

`Unity Editor Only`

Holds the TextureData for every channel in a control texture

In a class for serialization

## Variables

| Variable | Description |
|----------|-------------|
| ChannelTextures | A length of 4 with each index assigning to a target texture channel<br />0 = R, 1 = G, 2 = B, 3 = A  |
